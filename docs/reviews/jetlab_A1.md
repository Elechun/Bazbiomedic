# jetlab 부록에 대한 A1 검토 (Opus) — 요약

- 바즈바이오메딕 공개 공고는 기기·실험·QC·영업 직무 중심이며, 영상 AI 직무는 확인되지 않음. 공고 49918325 본문은 접근 불가.
- 참고문헌 5건은 저자·연도·저널 모두 정확. 보완: Ham & Yoh 2021 은 Med. Eng. Phys. 92:54-63; Lee 2022 는 Clin. Anat. 35(5):682-685 (Corrigendum 있음).
- 물리 타당성: 기본 설정의 최종 침투 깊이 6000 um, 데모 목표 4000 um 는 문헌의 유두진피 표적 약 300 um 및 샷당 0.1~1.7 uL 미세분할 분사 대비 한 자릿수 과대. 300~1500 um 로 재설정 권장.
- "CV R² 0.98" 은 synth 가 깊이를 v0·tau 로 생성하고 predict 가 v0·tau 를 피처로 받는 순환 논증. "합성 데이터 자기일관성" 으로 표현을 낮춰야 함. "표면 검출 오차 0 px" 도 계단형 합성 경계라 자명.
- 포지셔닝 제안: "영상 AI" 보다 "미세분할 분사의 샷 간 용량 재현성 QC 도구" 로 프레이밍하고, 합성 데이터 단계임을 README 상단에 선언.

(전문은 세션 기록 참고. 메인 프로젝트가 두피 분류로 바뀌어 jetlab 은 수정 없이 부록으로 남김.)
